Ігрові C++ скрипти зберігаються в папці scripts усередині кожного створеного проєкту.

Main.cpp містить onStart(Scene&) та onUpdate(Scene&, float).
Додаткові *.cpp можна створити кнопкою "+ New C++ Script" у нижній панелі.
generated_game.cpp створюється автоматично під час Run або Export і не є файлом для ручного редагування.
